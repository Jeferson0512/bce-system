# BCE System v1 legacy

Esta carpeta conserva la aplicación original de BCE System, congelada como
`v1.0.0`. No forma parte de la aplicación React de Fase 2 y no debe recibir
funcionalidades nuevas.

## Ejecución local

Abre `index.html` con un servidor estático desde esta carpeta para mantener
funcionales sus rutas relativas:

```text
legacy-v1/
  index.html
  css/
  js/
  database/
```

La aplicación usa JavaScript vanilla y datos locales del navegador. La base
React actual se encuentra en `apps/web`.
